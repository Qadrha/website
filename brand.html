Colour discipline: The four-tone cyan spectrum (#00c4ff → #0090cc → #006db5 → #004d8a) forms the segmented Q ring and should only be used in this rotational order. The Action Red (#FF4564) is reserved exclusively for the end dot, error states, and critical alerts — never use it decoratively. The background field (#0a0f1e) must always be dark navy; never place the logo on black (#000000) or coloured backgrounds.

06 — Usage Rules
✓ Do
  • Always use on #0a0f1e dark navy or very light (#f0f8ff+) backgrounds
  • Maintain clear space of at least 1× the mark width on all sides
  • Use the mark at minimum 24dp / 24px (legibility floor)
  • Keep the red dot always at #FF4564 — it is a brand constant
  • Use the Arabic wordmark (قدرها) as the primary wordmark in all KSA contexts
  • Use the four-segment sequence A→B→C→D (deep→highlight, clockwise)
✗ Don't
  • Don't recolour the red dot — no cyan, gold, or white dot variants
  • Don't rotate the mark — the diagonal cut must always run lower-right
  • Don't use on coloured backgrounds (green, orange, etc.)
  • Don't remove the diagonal stroke cut or the end dot
  • Don't scale below 20dp — segments become indistinguishable
  • Don't add drop shadows, gradients, or glows to the mark itself
